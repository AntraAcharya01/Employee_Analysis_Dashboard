# Employee Attrition Analysis Dashboard – Power BI

## Overview
This project is a Power BI dashboard focused on analyzing employee attrition trends and identifying patterns behind employee turnover. The dashboard provides insights into which employees left the company based on factors such as age group, education, salary slab, and year-wise attrition trends.

## Key Insights
- Year-wise employee attrition analysis
- Attrition distribution across different age groups
- Impact of education and salary slab on employee turnover
- Average years spent by employees before leaving the company
- Interactive visual storytelling using charts and KPIs

## Tools & Technologies Used
- Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Calculated Measures & KPIs)
- Interactive Power BI Visualizations

## Features
- Dynamic and interactive dashboard
- Data cleaning and preprocessing using Power Query
- Custom DAX measures for attrition analysis
- Visual representation of workforce trends and employee behavior

## Objective
The goal of this dashboard is to help understand employee retention patterns and support data-driven HR decision-making through meaningful visual analytics.
